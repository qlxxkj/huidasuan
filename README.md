# 亚马逊 FBA 利润计算器（微信小程序）

一个可本地保存、多站点、可导出历史的 FBA 单品利润计算小程序。纯原生微信小程序实现，无外部依赖、无后端，可直接导入微信开发者工具运行。

## 功能特性

- **多站点**：US / CA / UK / DE / FR / IT / ES / MX / JP / AU / SG / AE，一键切换币种与费率
- **分享**：计算页 / 历史页均可「分享给好友」，计算页分享会带当前站点与类目，对方打开直接进同站点
- **费用项齐全**：销售佣金、FBA 配送费（按尺寸/重量自动匹配费档）、采购成本、头程物流、增值税、关税、广告费、其他杂费、退货损耗
- **实时计算**：输入即时显示净利润、利润率、ROI（对货值）及各项费用明细
- **历史管理**：单条保存到本地、删除、清空、查看
- **导出**：一键复制「文本摘要」或「CSV」到剪贴板（可粘贴到 Excel），纯本地不依赖后端

## 如何运行

1. 打开 **微信开发者工具**
2. 导入项目 → 选择本目录（包含 `project.config.json` 的文件夹）
3. AppID 使用测试号 / 你自己的 AppID 即可（默认 `touristappid` 预览）
4. 编译运行

> 真机预览：开发者工具 → 预览 → 扫码。

## 如何修改费率 / 费档

所有可调参数集中在 `data/fees.js`：

- `REFERRAL_FEES`：各站点销售佣金费率（按类目）
- `FBA_TIERS`：FBA 配送费档（尺寸/重量 → 费用）
- `TAX_RATES`：各站点默认增值税率
- `AD_DEFAULT.cpcRate`：缺省广告费占售价比例

> ⚠️ 当前费率为**演示基准**，亚马逊费率会随政策调整，请以官方最新公告更新此文件。

## 计算口径说明

| 项 | 口径 |
|----|------|
| 销售佣金 | 售价 × 类目费率 |
| FBA 费 | 按最大边/重量匹配最近费档 |
| 增值税 | 售价 × VAT%（未做含税/未税区分，简化处理） |
| 关税 | 采购成本 × 关税% |
| 广告费 | 优先 `月预算/月销量`，其次单次 CPC，缺省为 售价×15% |
| 净利润 | 售价 − 各项成本之和 |
| 利润率 | 净利润 / 售价 |
| ROI | 净利润 / (采购成本 + 头程) |
